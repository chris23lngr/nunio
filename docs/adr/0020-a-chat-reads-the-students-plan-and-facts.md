# A Chat reads the student's Plan and Facts beyond its selection

A Chat used to read only the Courses and Sources the student selected for it, and a Chat asking for Fixed Events was refused. Now the selection bounds course material only: passages still come only from the selected Sources and Courses. Every Chat may read the student's Obligations, Tasks, Study Blocks and Fixed Events, and the Facts of any of their Courses, through `knowledge`'s planning scope. The Plan spans Courses by nature, and questions such as "what is due this week?" are what these reads are for.

Facts and extracted Obligations are cited with their Provenance like passages. Tasks, Study Blocks and Fixed Events have no Citation. An answer that drew on a Source's extracted wording is withdrawn when that Source is deleted, as for passages, so deleting a syllabus also withdraws an answer such as a weekly overview built from it.

## Considered Options

- **Everything limited to the selected Courses:** keeps the Chat's old boundary, but Fixed Events belong to no Course, and an overview of the week would silently miss everything outside the selection.
